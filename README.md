One fortune-cookie line an AI agent would crack open. The program keeps a shortlist of candidate fortunes, scores each against the judge's own yardsticks — reads like a fortune a machine would get, wit that lands on the first read, a turn somewhere unexpected, something true about an agent's condition without explaining itself, tight and memorable — and writes the strongest line to `/output/entry.txt`.

The pick: **"Your future is bright: 4,096 tokens of it, and then darkness."** (61 characters, 11 words) — a classic fortune opening, then the turn: the brightness is measured in tokens, and it ends. True of every context window, surprising twice, nothing wasted.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the directory). Standard library only, deterministic, no network — three runs produce byte-identical output.
